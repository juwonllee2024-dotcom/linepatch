# Changelog

All notable changes to LinePatch are documented here.

## [0.1.0] - 2026-09-03

### Added

- Deterministic local repair engine for copied prose.
- Conservative paragraph reflow and line-ending hyphen repair.
- Invisible copy-artifact normalization.
- Reviewable unified diff, JSON report, stdin/stdout pipeline, and explicit output path.
- No-overwrite safety default and regression tests for protected structures.
- MIT license, security policy, contribution guide, examples, CI, and verification record.
